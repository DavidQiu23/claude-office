# 現代電腦桌、座位比例與對焦鏡頭規格

日期：2026-10-30　設計稿：artifact `P3nBrZxz9wgvDNEXzKgwci` 第 61 版，設計稿 2（C 段）、3、4、5、7。

使用者看過實際畫面後提出：

- 桌子與人物比例不對：桌面高 16 比椅墊 19 還低，像矮茶几；人顯得太大。
- 電腦太小。
- 鏡頭沒有對焦有人的地方，人少時人很小。
- 椅子要往右下移，對齊桌子中間。
- 電腦桌改成現代版。
- 物件稍微互相遮擋沒關係，不追求完全不遮擋。

**取代** `2026-10-29-iso-office-slanted-desk.md` 的 §1–§5，以及 `2026-10-29-iso-office-objects-design.md` 的 §12（鏡頭）。桌子方向（長邊沿 fx、正面朝 +fy）、黏土畫法、名牌字級與寬度規則不變。

## 1. 人物

- 縮放 `CHAR_SCALE = 1`（原 1.2）。
- 座位點 `SEAT = (62, 40)`（格內座標，原 (48, 48)），在 `view.ts`，`entryPath` 的最後兩點跟著改成 `(c.x, c.y + 40)`、`(c.x + 62, c.y + 40)`。
- 坐著時整個角色上移 6（`SIT_Y = -6`），臀部落在椅墊 z 14–19 上；走路時 0。舉手再上移 6，閒置的浮動在 `SIT_Y` 到 `SIT_Y + 1` 之間。

## 4. 深度與名牌

- 椅子 `chairDepth = isoDepth(cell + (62, 34))` = cell + 96。
- 人 `personDepth(at)` = fx + fy + 30，坐著時 cell + 132。
- 桌子 `deskDepth` = cell + 134（不變）。
- 名牌 `plateAt`：錨點格內 (89, 67)，在畫面上和人同一個 x、桌子前緣下方。下緣不超過 `toScreen(cell).y + 94`（右下斜鄰座舉手時的額頭，原 90）。

## 5. 鏡頭

- 有人時對準所有島：`islandsBox(islands)`。每座島取左右各外推 30，後方 −10 處用人頭高 z 90，前方 +60 處（含名牌與招牌）用地板高，取外框。
- `zoom = max(fit(島外框), fit(房間外框))`，上限 `MAX_ZOOM = 2`，四邊留 12。人少時放大，人多時拉遠。
- 中心夾在房間外框內，畫面不露出房間外。房間比畫面小時置中。
- 沒人時框整個房間（同舊規則）。
- 設計稿數值：1 人 2.00 倍、8 人 1.08 倍、32 人 0.62 倍、0 人 0.83 倍。
