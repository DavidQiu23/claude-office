## 意圖

使用者想把整個畫面的美術重新設計，版面與功能不變。討論後定案：

- **背景與介面是手繪紙張風**：米色紙牆、鉛筆排線、墨線描邊、紙卡介面。
- **人物與物件是日式漫畫風**：墨線輪廓、網點陰影、大眼睛高光，加上漫符（集中線、「！」框、汗滴、「噠噠」、「zZ」）。漫符剛好用來加強「一眼看出誰在等你」。
- **依時間顯示白天或夜晚**。
- 整體風格一致：狀態列、電梯面板、資訊卡也跟著換。

核心需求不變：打開畫面最想一眼知道「有哪些專案」與「哪些 session 在等我」。

### 分成兩個子專案

1. **子專案 1（本文件）：新畫風**。人物、物件、背景、介面全部重畫；日夜切換；現有姿勢用新畫法做出來，加上坐下／站起來的過場。完成後功能與現在完全相同。
2. **子專案 2（之後另寫規格）：人物動作**。伺服器的員工資料加「工具類型」欄位、依工具換動作、等待時的小動作、完成歡呼、助理交文件。建立在子專案 1 的 SVG 部件上。

## 目標

- 人物與物件改用**行內 SVG 部件**繪製，動作用 CSS 讓部件旋轉、位移。
- 所有顏色都是 CSS 變數，白天、夜晚各一組；切換時只換變數。
- 拿掉 Canvas 黏土畫法（`clay.ts`、`flat.ts`、`sprites.ts`）。
- 狀態辨識比現在更醒目。

## 非目標

- 不改伺服器 `src/`（工具類型欄位是子專案 2）。
- 不做子專案 2 的任何動作：依工具換動作、等待時的小動作、歡呼、助理交文件、走去飲水機。

- 不改版面：`GEO` 的層高、座位寬、電梯區寬、家具區寬、電梯面板位置都不變。

- **紙張風**：墨線 1.6px（`--ink`），圓線頭、圓轉角。牆面每層有一兩片鉛筆排線（`--hatch`，1px 斜線），位置只跟樓層寬度有關，重畫不跳動。

## 日夜切換

- `web/src/theme.ts`：
  - `timeOfDay(date: Date): 'day' | 'night'`：本地時間 6:00（含）到 18:00（不含）為 `day`，其餘為 `night`。純函式。
  - `themeOverride(search: string): 'day' | 'night' | null`：網址參數 `time=day` 或 `time=night` 時回傳該值，其他值或沒有參數回傳 `null`。純函式。
  - `startTheme()`：有覆寫就固定用覆寫值；否則設定一次 `document.documentElement.dataset.time`，之後每 60 秒檢查一次，到點直接換（沒有過渡動畫）。
- `main.ts` 在建立大樓之前呼叫 `startTheme()`，第一次繪製就是正確的配色。
- 系統深色模式不影響，只看時間。

## 畫法架構

### 原則

只換「怎麼畫」，不動「畫什麼、放哪裡」。下列模組的邏輯不變：`floors.ts`（樓層配置、座位、邊緣提示、走路計時）、`sync.ts`、`door.ts`、`view.ts` 的 `summary`／`nameplate`／`assistantList`。

### SVG 的產生方式

- 人物與物件都由**純函式產生 SVG 標記字串**（不碰 DOM），可在 vitest 的 node 環境測試。DOM 端用 `innerHTML` 放進去；字串裡只有程式自己產生的內容，不含任何使用者或 prompt 文字。
- **顏色一律用 `style` 或 class 指定**（例如 `style="fill:var(--desk)"` 或 `class="ink"`），**不可**寫在 `fill="..."`／`stroke="..."` 屬性裡：SVG 呈現屬性不接受 `var()`，寫了日夜切換不會生效。外觀色（衣服、髮色）是固定值，可以直接寫在 `style` 裡。
- 共用樣式 class：`ink`（紙張風墨線）、`fig`（漫畫墨線 1.5）、`fig-thin`（1.1）、`tone`（填網點）。

### 姿勢與漫符

`person.ts` 的 `Act` 不變（`work`、`up`、`idle`、`walk`、`stand`），對應：

| Act | 狀態 | 姿勢 | 漫符 |
|---|---|---|---|
| `work` | 工作中 | 坐著，兩手輪流上下 3px，週期 0.42s，左右錯開半週期 | 「噠噠」效果字（14px，`--fx`）在桌子左上方，每 0.84s 閃一次；兩手外側各一條動態線 |
| `up` | 等你處理 | 站起來（`.fig` 上移 12px），右臂轉到頭上，在 160°–195° 之間揮動，週期 0.8s；眼睛睜圓、嘴巴張開 | 頭頂半圈集中線（見下）；尖角框「！」（白底、`--waiting` 色字）在頭的右上方，每 1.6s 放大到 1.12 倍再縮回；汗滴在頭左側往下滑，週期 1.6s |
| `idle` | 輪到你 | 坐著閉眼，頭每 2.6s 點一次（轉 −6°） | 琥珀打勾泡泡（圓形，半徑 11，墨線框）在頭的右上方；「z」「Z」在頭的左上方輪流往上飄，週期 2.6s |
| `walk` | 走路 | 腿與手臂交錯擺動 ±16°，週期 0.56s；身體上下 1.5px | 無 |
| `stand` | 站著不動 | 站姿、手放下 | 無 |

- **集中線**：以頭中心為圓心，角度 −170° 到 −10° 每 14° 一條；從半徑 30 畫到半徑 44，每隔一條畫到 52 並加粗（1.8px，其餘 1px）。每 1.6s 淡到 0.35 再回來。
- **坐下／站起來的過場**：`.fig` 的位移、腿的收合、椅背的顯示用 CSS `transition` 300ms，`data-act` 一換就自動播。300ms 與 `building.ts` 的 `STAND_MS` 相同，所以「站起來停一下再走」的節奏不變。
- **範圍限制**：所有漫符都在座位中心 ±60 的範圍內（座位寬 120），不會蓋到隔壁的人或名牌。實作時以 crm 那層坐滿 8 人的畫面驗證。
- **助理**：同一套人物，新增縮小到 0.85 倍（`transform: scale(0.85)`，以腳底中心為基準；現在助理與員工一樣大），讓主人與助理一眼分得出來。與現在一樣不舉手、沒有泡泡；工作中照樣有打字動作與「噠噠」。`building.ts` 建立助理的 `Person` 時在元素上標 `data-kind="assistant"`。

### 減少動態

`@media (prefers-reduced-motion: reduce)` 時：

- 所有 `animation` 停止，過場的 `transition` 也取消。
- 漫符停在可見的那一格：集中線、「！」框、汗滴、「噠噠」、「z」「Z」都靜止顯示。
- 姿勢仍然正確（等你處理照樣站著舉手），所以狀態看得出來。
- 走路照現在的做法：直接放到目的地。

## 物件

### 共同規則

- 每件物件是 `objects.ts` 裡的一個 `<symbol>`，用 `<use>` 放上去。原點在底邊中點，與現在的家具相同。
- 物件表記錄每件的 `id`、寬、高與「站位」（人要使用這件家具時站的 x 偏移；子專案 2 才會用到，這次只定義）。
- 漫畫墨線＋暗面網點，顏色全部用主題變數。

### 桌子

- 寬 112、桌面上緣與現在的桌面位置相同（`floor.ts` 的 `DESK_Y` 換算後桌面在樓層 y 143.5），高到樓板。
- 木桌，桌面下緣一條網點陰影；桌上有鍵盤、馬克杯、筆記本。
- 螢幕在桌面右側（不擋臉），四種狀態：

| 桌子狀態 | 螢幕 | 其他 |
|---|---|---|
| 空桌 | `--screen-off` | 夜晚不開檯燈 |
| 工作中 | `--screen-working` | |
| 等你處理 | `--screen-waiting` | 桌面混一點紅（同現在的做法） |
| 輪到你 | `--screen-turn` | 杯子冒蒸氣 |

- 四種狀態做成四個 symbol（`desk-empty`、`desk-working`、`desk-waiting`、`desk-idle`），狀態判斷沿用 `floor.ts` 的 `deskState`。
- **檯燈**：夜晚有人的桌子在左側多一盞檯燈，人周圍一圈 `--lamp-glow` 暖光；白天與空桌不顯示。用 CSS 依 `data-time` 控制。
- **名牌**仍是 HTML 文字（13px、最寬 112、放不下用「…」），只把外框改成 1.4px 墨線、拿掉陰影。

### 電梯（每層左端）

- 漫畫墨線的門框與兩片門，右片門貼網點，門上的小螢幕顯示樓號。
- 開關門仍是兩片門左右滑開 300ms，`door.ts` 的時序不變。

### 窗

- 紙張風墨線窗框，窗裡是遠方城市。白天：藍天、白雲、淡色的樓；夜晚：深藍天、星星、月亮、亮燈的窗。
- 一個 symbol，城市與天空的顏色用變數，日夜共用；白雲與星星各是一個群組，依 `data-time` 顯示。
- 位置規則（`windowXs`）不變。

### 右端家具組

沿用現有 4 組與 `furnitureSet` 的挑選規則：

| 組 | 內容 |
|---|---|
| `pantry` 茶水間 | 飲水機、販賣機、盆栽 |
| `library` 書房 | 書櫃、影印機、盆栽 |
| `lounge` 休息區 | 立燈、沙發、邊桌 |
| `reading` 閱讀角 | 書櫃、邊桌、立燈 |

- 8 種家具全部重畫成漫畫風，尺寸接近現在的版本，讓 `layoutSet` 排出來的位置相近。
- 夜晚：販賣機燈箱與立燈亮起，周圍一圈 `--lamp-glow`。

### 屋頂與地面

- 屋頂：女兒牆、水塔、冷氣機、天線，紙張風墨線。夜晚天線頂端紅燈每 1.8s 閃一次（減少動態時不閃）。
- 地面：人行道磚縫、路緣，紙張風，日夜換色。
- 天空：白天有太陽與白雲，夜晚有月牙與星星，都是紙張風墨線。

## 介面元件

共同規則：紙色底（`--paper`）、1.6px 墨線框、圓角，沒有陰影與漸層；內容、行為、位置都不變。

### 狀態列

- 紙卡，圖例「! 等你處理」「✓ 輪到你」「● 工作中」、右邊「共 N 位」、下面比例條；比例條三段各加墨線框。
- 外框：有人等你處理時是 `--waiting` 色、2.6px；只有人輪到你時是 `--turn` 色、2.6px；其他時候是一般墨線。（沿用 `summary` 的 `alert`／`turn`。）
- 人數 0 的項目變淡（同現在）。

### 電梯面板

- 紙色長條圓角卡，一層一顆圓鈕（直徑 28，墨線框，樓號在中間）。
- 等你處理的樓層填 `--waiting`、白字；輪到你的填 `--turn`、深字；其餘填 `--button`。拿掉發光效果。
- 目前看得到的樓層用虛線框框起來（取代現在的半透明白框）。
- 滑過顯示專案名稱、點了捲到那層，不變。

### 資訊卡

- 紙卡加墨線框，頂端一條專案色。
- 內容與順序完全不變（頭像、標題、狀態標籤、專案資料夾；正在做的事；最近與第一個 prompt；助理清單；到班時間與「請他下班」；助理卡片）。
- 頭像改用 `avatarSvg(look)`（頭與肩膀，表情固定是工作中的睜眼）。
- 「等你批准」那一塊照舊整塊用 `--waiting` 淡底。
- 「請他下班」改成墨線框按鈕，滑過時字與框變 `--waiting`。
- `card.ts` 裡所有寫死的行內顏色改成 class＋主題變數。

### 樓層邊緣提示

- 兩側暗影保留（寬 22px），改成從 `color-mix(in srgb, var(--ink) 35%, transparent)` 漸到透明，白天是淡褐、夜晚是深藍黑。
- 「! N ›」「✓ N ›」改成墨線框圓角標籤，底色 `--waiting`／`--turn`，行為不變。

### 招牌

- 專案色圓角牌、1.6px 墨線框、白色粗體字，放不下用「…」（同現在的寬度規則）。

### 空大廳

- 「目前沒有人上班」「開一個 Claude Code session 就會出現」改成貼在牆上的紙條（紙色、墨線框、微微歪 −2°）。

### 分頁標題

- 不變，例如「(!1 ✓2) Claude 辦公室」。

## 效能

- 每個人約 30 個 SVG 節點，桌子與家具都是 `<use>`。simulate 劇本最多約 20 人，總節點數在一千以內。
- 動畫全部是 CSS `transform`／`opacity`，不觸發版面重排。
- 不再有 Canvas 烘圖與人物圖快取（`CHAR_CACHE_MAX` 拿掉）。

### 瀏覽器檢查清單

用隔離的伺服器（HOME 指到暫存資料夾、另一個 port）跑 `npm run simulate`，分別用 `?time=day` 與 `?time=night` 走完整個劇本，逐項確認：

1. 工作中、等你處理、輪到你三種狀態一眼分得出來；夜晚的名牌、泡泡、漫符對比足夠。
2. crm 那層坐滿 8 人時，集中線、「！」框、汗滴、「zZ」都沒有蓋到隔壁的人或名牌。
3. 名牌文字清楚，長標題截斷成「…」。
4. 上班：電梯開門、走出來、坐下（有坐下過場）；下班：站起來、走回電梯；最後一人離開後樓層拆掉。
5. 助理縮小、坐在主人旁邊打字，完成後離開；不舉手、沒有泡泡。
6. 狀態列外框與電梯燈色正確；看得到的樓層有虛線框；邊緣提示正常且可點。
7. 員工與助理的資訊卡內容正確、頭像是漫畫人物；「請他下班」有效。
8. 夜晚：檯燈只在有人的桌子亮；販賣機、立燈發光；天線紅燈閃。
9. 不帶網址參數時依目前時間顯示；改系統時間跨過 6:00 或 18:00，一分鐘內自動切換。
10. macOS 開啟「減少動態」後，所有動畫停住，狀態仍看得出來。
11. console 沒有錯誤。
