## 1. 共通規則

- 投影 `toScreen(fx, fy, z) = { x: fx − fy, y: (fx + fy)/2 − z }`。世界單位 = 地板 px，K = 1，縮放交給鏡頭。
- 方塊 `isoBox(x0, y0, x1, y1, z0, z1, top, left, right)`：先畫左面（fy = y1）、再右面（fx = x1）、最後上面。只給基色時：上 = `mix(基色, #ffffff, 0.18)`、左 = 基色、右 = `mix(基色, #1d1a2e, 0.2)`。
- 牆面上的圖形：後牆是 fy = 常數的面（u = fx、高 z），左牆是 fx = 常數的面（v = fy、高 z）。方塊正面上的細節（書背、門、窗）畫在該方塊左面那個 fy 平面上。
- 牆上的圓（時鐘、燈）是 24 點的多邊形近似；地上的圓／光是 2:1 橢圓（地板座標的圓，28 點）。
- 看板：角色、葉子、貓、懶骨頭維持平面插畫；素材錨點對到地板點（可帶 z，例如盆口高度）。
- 每個物件一個深度，同物件內照畫的順序。

## 8. 座位幾何（新）：人、椅、桌、螢幕對齊同一條視線

座位格原點 = `seatCell()` 左上角。人仍在 `PERSON = (48, 48)`（entryPath 不改）。

桌子、椅子、螢幕改成**轉 45° 的方塊**：沿 u = (1,−1)/√2、v = (1,1)/√2 擺，正面（法向 +v）朝觀看者。這種方塊只看得到上面與正面兩面，在畫面上是兩個水平矩形。

```
rpt(c, u, v, z) = (c.x + (u + v)/√2,  c.y + (v − u)/√2,  z)
桌子中心 D = cell + (59, 59)         // = 人 + 11·(1,1)，所以 toScreen 的 x 相同：人、螢幕、桌子垂直對齊
```

## 16. E 黏土：實作規格

全部在**烘貼圖時**完成（執行時仍是一般 Image），不用 shader、不用外部素材。烘焙從 `Graphics.generateTexture` 改成 Canvas 2D：

```ts
const tex = scene.textures.createCanvas(key, w * PIXEL_RATIO, h * PIXEL_RATIO);
const ctx = tex.getContext();            // CanvasRenderingContext2D
ctx.scale(PIXEL_RATIO, PIXEL_RATIO); ctx.translate(-x0, -y0);
// …逐一畫圖形…
tex.refresh();
```

房間（地板、牆、地毯、地墊）可以照現在用 Graphics 畫在場景上，只要另外描一條圓角邊（Canvas 版或 `lineStyle` 都可）。

### 16.1 方塊類（牆邊家具、桌、椅、螢幕、掛件、門、盆栽的盆）
每個面（多邊形 `p`、顏色 `c`、不透明時）：
1. `ctx.fillStyle = c; ctx.fill(path)`。
2. 圓角邊：`ctx.lineJoin = 'round'; ctx.lineWidth = 1.4; ctx.strokeStyle = mix(c, '#1d1a2e', 0.18); ctx.stroke(path)`（圓角約半徑 0.7，縮放後就是軟邊）。
3. 亮塊：面積 < 3000（世界 px²）的面才加。點 = 中心 o + (q − o) × (0.62, 0.55) − (0.8, 0.8)；`fillStyle = mix(c, '#ffffff', 0.32)`，`globalAlpha = 0.45`。形狀與原面相同、縮小、往左上偏。
- 方塊三面的基色規則不變：上 = 基色 +18% 白、左 = 基色、右 = 基色 +20% `#1d1a2e`。
- 半透明的面（α < 1：光暈、玻璃反光、陰影）只填色，不描邊、不加亮塊。
- 狀態燈與光暈不套效果。

### 16.2 房間（地板、牆、牆頂、地毯、區域地墊、門墊）
- 只描邊：`lineWidth = 1`、`strokeStyle = mix(c, '#1d1a2e', 0.12)`、`lineJoin = 'round'`；不加亮塊、不加漸層。
- 棋盤格與格線（α 0.025／0.05）不描邊。

### 16.3 人物（頭、身體、頭髮、手、衣服細節；素材座標 40×56，再 ×1.2）
| 圖形 | 填色 | 漸層座標（以該圖形外框 x, y, w, h 計） | 色階 |
|---|---|---|---|
| 圓角矩形、多邊形（身體、手臂、腿、頭髮塊、衣領） | `createLinearGradient` | 起 (x, y) → 迄 (x + 0.35w, y + h) | 0：`mix(c,'#fff',0.30)`；0.55：`c`；1：`mix(c,'#1d1a2e',0.25)` |
| 圓、橢圓（頭、手、髮髻、眼睛、腮紅） | `createRadialGradient` | 圓心 (x + 0.38w, y + 0.34h)，r0 = 0，r1 = 0.75·max(w, h) | 0：`mix(c,'#fff',0.45)`；0.45：`c`；1：`mix(c,'#1d1a2e',0.28)` |
- 圓角矩形照原本的 `r`（`ctx.roundRect` 或 arcTo）。
- 高光：半徑 > 3 的圓（頭 r 12.5、髮髻等）加一顆白橢圓，中心 (cx − 0.35r, cy − 0.42r)、rx 0.32r、ry 0.2r、`globalAlpha = 0.55`。
- 半透明圖形（腮紅 α0.65 等）照原色填、不加漸層。
- 眼睛、嘴的小圓同樣走放射漸層（很小，視覺上就是一點亮面）。
- 資訊卡頭像用同一套。
- 看板類的葉子、貓、懶骨頭同人物規則。
