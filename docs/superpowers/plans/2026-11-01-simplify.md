# 簡化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 助理改成主人名牌旁的「↳N」小標、拿掉邊緣提示與樓層左右捲動（各層同寬、整頁橫向捲動）、刪掉過時文件、合併重複的 SVG 小工具。

**Architecture:** 只動前端 `web/` 與文件；伺服器 `src/` 不動，助理照樣記在 `Employee.assistants`。`floors.ts` 的純計算先改（座位只坐員工、名牌多回傳助理數、新增全樓共用寬度），`building.ts`／`floor.ts`／`card.ts` 跟著拿掉助理人物與每層捲動容器。

**Tech Stack:** TypeScript、Vite、vitest；無框架，DOM 手寫。

**Spec:** `docs/superpowers/specs/2026-11-01-simplify-design.md`

## Global Constraints

- 不改 `src/`、`scripts/`；不新增相依套件。
- 註解與 commit 訊息用繁體中文，風格照現有程式（行內短註解、`feat:`／`refactor:`／`docs:` 前綴），commit 結尾加 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。
- 每個 task 結束時 `npm test` 與 `npm run build` 都通過。
- 小標文字是「↳N」（N = `status === 'working'` 的助理數），N 為 0 不顯示；配色沿用原本助理名牌 `#dfeedd` 底、`#2f4a32` 字。
- 樓層寬 = `floorWidth(全部樓層最多的桌數, 可用寬)`，可用寬算法不變（`clientWidth − GEO.gutter − GEO.rightMargin`）。
- 保留 `web/src/motion.ts`、hook 的 `--record`、電梯進出動畫、日夜、樓層順序與捲動錨定。

## Review Focus

- 名牌標題很長又有助理：文字被「…」截短，「↳N」整個看得到 → Task 3 的 CSS 測試。
- 背景助理（`run_in_background`）在主人 Stop 後仍在跑：小標仍算它 → Task 3 的 reduce 串接測試。
- 頁面橫向捲到最右：狀態列整條仍在視窗內、電梯面板固定在左 → Task 4 的 CSS 測試與瀏覽器檢查。
- 最寬那層的人走光、拆樓後：頁面寬度縮回、橫向捲軸消失 → Task 4 的 `buildingWidth` 測試與瀏覽器檢查。
- 已橫向捲動時點電梯按鈕：只上下捲，不左右跳 → Task 4 的瀏覽器檢查。
