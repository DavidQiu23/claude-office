# Triage 標籤

skill 用五個固定的 triage 角色溝通。這份表把角色對應到這個 repo 實際用的標籤字串。本機 tracker 沒有真正的標籤，字串寫在每張票的 `Status:` 行。

| mattpocock/skills 的標籤 | 我們用的標籤      | 意思                           |
| ------------------------ | ----------------- | ------------------------------ |
| `needs-triage`           | `needs-triage`    | 維護者需要評估這個 issue       |
| `needs-info`             | `needs-info`      | 等提出者補充資訊               |
| `ready-for-agent`        | `ready-for-agent` | 規格完整，可以交給 agent 做    |
| `ready-for-human`        | `ready-for-human` | 需要人來實作                   |
| `wontfix`                | `wontfix`         | 不處理                         |

skill 提到某個角色時（例如「套上 AFK-ready 的 triage 標籤」），用這張表對應的字串。

要換成自己的用詞，就改「我們用的標籤」那一欄。
